# Instalar ChatGPT

Puedes usar ChatGPT desde un navegador sin instalar nada o mediante la aplicación de escritorio. Elige la opción que se adapte a tu equipo y al tipo de trabajo que quieras realizar.

## Opción 1: usar ChatGPT en el navegador

1. Abre [chatgpt.com](https://chatgpt.com).
2. Inicia sesión con tu cuenta de ChatGPT o crea una cuenta si todavía no tienes una.
3. Inicia un chat y escribe tu primer mensaje.

Esta opción es suficiente para aprender, hacer preguntas, explorar ideas y trabajar desde cualquier equipo compatible con un navegador moderno.

## Opción 2: instalar la aplicación de escritorio

La aplicación de escritorio está disponible para macOS, Windows y Linux. Es una buena opción si trabajarás con archivos locales, proyectos o tareas de larga duración.

1. Abre la [página oficial de descarga de ChatGPT](https://chatgpt.com/download).
2. Elige la versión para tu sistema operativo.
3. Descarga e instala la aplicación siguiendo las indicaciones de tu equipo.
4. Abre ChatGPT e inicia sesión con tu cuenta.

Después de iniciar sesión puedes comenzar un chat, crear un proyecto o abrir una carpeta para trabajar con sus archivos. Otorga permisos de acceso a archivos solo cuando entiendas qué tarea los necesita.

## Primer mensaje recomendado

Una vez dentro de ChatGPT, prueba con una petición concreta:

```text
Quiero aprender a crear una página web sencilla para un negocio local.
Explícame qué necesito, en qué orden debo hacerlo y qué puedo probar hoy.
No asumas que ya conozco herramientas de programación.
```

Lee la respuesta, pregunta por las palabras que no conozcas y pide un paso a la vez. No compartas contraseñas, códigos de acceso, llaves API, certificados ni datos personales innecesarios.

## Si usarás Codex más adelante

Para crear o modificar software en un repositorio, el siguiente paso será usar Codex desde la aplicación de escritorio, la terminal o una extensión compatible. Antes, familiarízate con ChatGPT y con cómo escribir una tarea clara.
