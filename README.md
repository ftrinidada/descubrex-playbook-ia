# Playbook IA

Manual para el aprendizaje práctico con IA, ChatGPT, Codex y GitHub al crear proyectos: sitios web, aplicaciones móviles, juegos, automatizaciones, herramientas o cualquier idea que tengas en mente.

> Este repositorio es una guía educativa. No contiene código privado, llaves, tokens, certificados, perfiles de firma ni datos personales.

## Objetivo

Inspirar a cualquier persona a descubrir el poder de la inteligencia artificial, aprender con curiosidad y transformar una simple idea en algo útil, creativo y real que pueda compartir con el mundo.

## Principios para las publicaciones

- El documento puede ser público; no publiques secretos, datos privados ni código que no tengas permiso de compartir.
- Un cambio pequeño no siempre amerita una versión mayor: se usa versionado semántico como guía cuando corresponde.
- Automatizar no sustituye el juicio humano. Producción, gastos, mensajes a terceros y acciones irreversibles deben tener una aprobación explícita.
- Antes de compartir, revisa texto, capturas y archivos para evitar tokens, correos privados, IDs de perfiles o rutas personales.
